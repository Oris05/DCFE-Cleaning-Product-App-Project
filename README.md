# DCFE Cleaning Product Shop Project
A small project built using HTML, CSS, and JavaScript.
It displays a basic list of cleaning products and includes a simple add‑to‑cart feature implemented with JavaScript.

# Purpose
This project was created during my time at DCFE, for one of my modules.

# How to Run
Just open index.html in any browser.
No backend, no dependencies.
